# Curated Keynote Design Themes & Color Palettes

A complete design token guide for creating visually stunning presentations in Keynote.

---

## Typography Pairings

- **Modern Tech / Apple Style**:
  - Title: `SF Pro Display Bold` (or `HelveticaNeue-Bold`)
  - Body: `SF Pro Text Regular` (or `HelveticaNeue`)
  - Code / Numbers: `SF Mono` (or `Menlo`)
- **Editorial / Academic**:
  - Title: `New York Bold` (or `Georgia-Bold`)
  - Body: `Georgia` (or `TimesNewRomanPSMT`)
- **Terminal / Engineering**:
  - Title: `SF Mono Bold` / `JetBrains Mono Bold`
  - Body: `SF Pro Text Regular`
  - Code: `SF Mono Regular`

## Layout Grid Standard (16:9 1920x1080 & 1280x720)

- **Canvas Margins**:
  - Left / Right Margin: `6%` of canvas width (`115px` for 1920w, `77px` for 1280w)
  - Top Margin: `6%` of canvas height (`65px` for 1080h, `43px` for 720h)
- **Header Zone**:
  - Title Y: `6%`
  - Subtitle Y: `11%`
- **Main Body Zone**:
  - Content Start Y: `22%`
  - Content Height: `70%`
- **Card Padding**:
  - Internal Padding: `24px` to `32px`
- **Multi-Column Gaps**:
  - Gap between cards: `2%` to `3%` of canvas width
